# GenAI-Reasoning-Chatbot-with-RAG-DeepSeek
Built an intelligent RAG-powered Legal Chatbot that combines LangChain, FAISS, Streamlit, and LLMs (DeepSeek-R1 & Llama-3.3) to perform context-grounded legal reasoning. The chatbot allows users to upload legal PDFs, automatically extract and embed the text into a vector database, and ask complex legal questions.

It retrieves relevant sections and generates logical, evidence-based answers using Groq’s Llama-3.3-70B-Versatile or Ollama’s DeepSeek-R1-7B models for reasoning. The project demonstrates end-to-end GenAI integration — from document ingestion and vector search to prompt engineering and structured LLM output — ensuring explainable, accurate responses.

This project showcases practical expertise in Retrieval-Augmented Generation (RAG), LangChain pipelines, FAISS vector stores, and LLM deployment, with applications in legal research, compliance, and document interpretation.
